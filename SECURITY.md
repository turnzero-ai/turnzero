# Security Policy

## Supported Versions

Currently, only the latest version of TurnZero is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.11.5 | :white_check_mark: |
| < 0.11.5  | :x:                |

## Reporting a Vulnerability

We take the security of TurnZero seriously. If you find a security vulnerability, please do not open a public issue. Instead, please report it via the "Report a vulnerability" button on the Security tab of the repository.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Security Brand Promise

TurnZero is built on a "local-first" privacy model:
- **Expert Priors** are stored on your local machine.
- **No Raw Prompts** are ever sent to TurnZero servers.
- **Telemetry** is anonymous, opt-out, and never includes identifiable code or prompt content.
